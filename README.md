# Anime-Generator - A small python library that allow you to generate video clips in the style of visual novels

## Installation
```bash
pip install -r requirements.txt
```

## Creating scenes
Character attributes are described in the "scripts/characters.json" file, character lines are described in the "scripts/dialogues.json" file. Character and background images are located in the "images" folder. 

## Generating video
```bash
./make_video.py
```

## Generating OTIO Timelines
```bash
./make_timeline.py
```
